# OpenHW 1.0 Windows source package

This is the complete current source tree. Follow [BUILD_INSTALLER.md](BUILD_INSTALLER.md)
to build both game variants and the single-file OpenHW-Setup.exe.

The current installer imports retail data and audio from the selected HWRM Collection.
It requires no manual audio copying, and stores application-owned files beside itself.
The approved content inventory and source snapshot manifest are included.
