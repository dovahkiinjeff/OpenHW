# Fleet badges

Open Fleet Identity / player colour setup and choose **Badge**. The preview shows the selected image on ship meshes with authored badge areas. Click **Custom Image** to choose PNG or DDS files; Windows multi-select is supported. Select a tile and **Apply** to save your choice, or choose **No Badge**. Previous / Next and the mouse wheel browse the library. Hover a tile to see its source.

Images are copied into **Badges** beside OpenHW.exe with content-based filenames. The original image is preserved, metadata records its name/source, and selected.txt stores the active choice. New imports stay in this library even if you cancel the colour dialog or later unsubscribe from their Workshop pack. Identical encoded files are deduplicated. Images must be valid 2D PNG or DDS files, at most 4096 by 4096 pixels and 16 MiB; DDS arrays, volumes and cubemaps are unsupported. Display images preserve aspect ratio and transparency within a 256-pixel square. Unsupported/corrupt images are skipped.

Opening the badge tab scans Steam library locations for the owned Remastered installation and installed Workshop content for app 244160. PNG, DDS and legacy TGA badge images in badge/badges directories, including compatible SGA v2 .big archives, are read without modifying the source pack. Only image data is imported: no Workshop Lua or other mod code is run. **Rescan** discovers newly installed files. Packs that use an unsupported archive format or nonstandard image location can supply a PNG/DDS through Custom Image instead. The library does not download unsubscribed Workshop content.

Rendering uses the native model's authored secondary badge coordinates. Some ships have no authored badge region. A badge does not replace hull paint or add a solid shadow-casting plate. Online games send a 96 by 96 RGBA copy through the server, independently of the permanent original. The server validates fixed dimensions and payload size and clears a player's badge when their slot is vacated. Cosmetic badges do not affect simulation checksums or activate gameplay mods.
