# Mixed fleet spread, concept panels and online directory

- Spread now supports any combination of owned ships in one standard formation: Delta, Broad, Delta 3D, Claw, Wall or Sphere. Custom and Military Parade are excluded. It preserves orders and uses hull-size clearance.
- All 15 supplied images are retained with provenance. Translucent artwork is used in Escape/in-game panels, large static UI panels, settings, workshop/parade/mod menus, online panels and Diagnostics.
- Online has a persistent server/match directory, three-second refresh, six rows per page, mouse-wheel and Previous/Next navigation through all 16 rooms, map/player/AI/capacity/state details, and click-to-join available rooms. Split panels replace the giant opaque lobby background.
- Server/client changes are staged together. Deploy the matching worker/fingerprint when releasing this update; do not replace the live server independently of clients.

This is an unpublished local candidate. The public 1.1.1 channel is unchanged. Interactive game/UI checks remain for the owner.
